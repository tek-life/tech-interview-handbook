量化技术总览：What / Why / How

量化（Quantization）是把高精度数值映射到低精度表示的过程，用更少的 bit 保存更多计算价值。它既是模型压缩技术，也是部署优化技术。

什么是量化？

可以把量化类比成 照片压缩：FP32 像 RAW 格式，保留全部细节但体积很大；INT8 像高质量 JPEG，在多数场景仍清晰；INT4 更像缩略图，体积极小但细节更容易丢失。

为什么需要量化？

8×

内存减少：FP32 → INT4 理论上减少 8 倍，意味着相同显存可容纳更大模型。

2–4×

速度提升：INT8 matrix multiply 往往比 FP16 / FP32 更快，尤其在 Tensor Core 或专用 NPU 上。

更低功耗

能耗降低：边缘设备、手机、工控盒子、普通笔记本都更容易完成本地推理。

量化的基本原理

最常见的是 linear quantization：用 scale 与 zero_point 把连续实数映射到离散整数。

Q(x) = round(x / S + Z)
其中：
S = scale，控制一个整数步长代表多少实数范围
Z = zero_point，让 0 尽量准确映射

量化的核心挑战

1. Outliers

少数极大值通道会拉宽分布范围，导致大部分普通数值被压到很粗的量化格点上。

2. Calibration

校准数据不代表真实分布时，scale 估计会偏离线上激活统计，从而造成显著精度下降。

3. Hardware Support

不是所有硬件都原生支持 INT4 / FP8；即使支持，kernel 实现、layout 与 memory bandwidth 也会决定真实性能。
